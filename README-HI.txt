TARUN FOLLOWERS Android Starter v1.1

UPI VPA configured: prsaini041@okhdfcbank

Demo features:
- New order form with amount field
- Opens installed UPI app using a UPI payment intent
- Orders are saved locally on the same device
- Admin demo login, PIN: 246810
- Admin can manually mark local orders Paid or Cancelled

IMPORTANT LIMITATIONS:
- This is a prototype, not a production-ready ordering/payment system.
- Orders are stored only in local storage on this phone; they do not reach you from customers' phones.
- Admin PIN is client-side demo protection and is NOT secure for public use.
- UPI payment success is NOT automatically verified. Check your bank/UPI merchant statement before marking Paid.
- Do not treat screenshots or customer claims as payment confirmation.
- A real public app requires a secure backend/database, server-side admin authentication, order APIs, payment verification/reconciliation, privacy policy and service-policy review.
- No Instagram password is requested. Only provide legitimate, policy-compliant promotion.

BUILD APK:
1. Install Android Studio and Android SDK Platform 35.
2. Open this project folder in Android Studio.
3. Wait for Gradle Sync.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK output: app/build/outputs/apk/debug/app-debug.apk

UPI QR:
- The QR screenshot supplied by the user has been cropped and added as app/src/main/assets/upi_qr.jpg.
- It is displayed in the payment section. Verify recipient and amount in the UPI app before paying.
